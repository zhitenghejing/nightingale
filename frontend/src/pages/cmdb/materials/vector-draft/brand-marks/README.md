# 品牌矢量参考

- Dell、Lenovo、Huawei：来自 [Simple Icons](https://github.com/simple-icons/simple-icons/tree/develop/icons)
  的对应品牌 SVG。保留路径；设备上的颜色依原图用浅色丝印。
  Dell 设备正面采用同源字形轮廓，不含外圆；Lenovo 使用同源字样轮廓，不含矩形背景。
- HPE：按官方开放绿色矩形标识的几何特征绘制。绿框是品牌本身的一部分，独立于统一机身灰阶。
- 浪潮信息：从 [浪潮信息官网标识](https://www.ieisystem.com/global/template/images/logo.png)
  提取矢量轮廓，保留中文品牌字形。参考硬件图属于不同标识批次，当前样稿明确采用浪潮信息标识。
- H3C：使用先前按官网 Logo 提取的矢量轮廓，见 h3c-s5130s-28s-ei/h3c-logo.svg。

品牌字形均为路径，不用近似字体重新拼写。普通型号、端口标签和说明文字使用系统字体。
品牌仍属于各自所有者；本目录记录图形来源。
