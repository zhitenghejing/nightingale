# H3C S5130S-28S-EI 矢量风格样稿

这是供用户确认画风的独立样稿，尚未修改 catalog.json、已发布面板和另外九款设备。

- `front.svg` / `rear.svg`：1200 × 120、透明底、自包含 SVG；可直接用于 1U 机柜面板。
- `preview.png` / `preview.svg`：正背面对照及风格规则，供聊天评审。
- `h3c-logo.svg`：官方 Logo 红色品牌字样的矢量轮廓，设备正面使用浅色丝印。
- `style.json`：样稿配色与结构来源。
- `build_sample.py`：读取本目录 Logo 并重新生成面板和 SVG 预览，不需要联网或图像处理库。

画风：正交视图、深灰机身、低幅度金属渐变、统一接口阴影与细边线；
型号布局独立绘制，品牌字形保留。所有图形均为 path/rect/circle 等矢量元素，
没有嵌入位图，没有把低清照片放大，没有字体依赖的品牌标识。
普通型号与端口文字使用系统字体；品牌 Logo 本身是轮廓路径。

网口卡扣缺口朝向：上排朝上、下排朝下，触点随插口方向翻转，金属边框光照方向保持一致。

正面含 24 个 RJ45 电口、4 个 SFP+ 插槽、RJ45 Console 和 Micro USB Console；
背面按本次官方参考中的电源、接地和通风孔结构简化绘制。
指示灯使用中性灰色，不能当作设备运行状态。
图形是运维展示用的简化素材，不是机械工程尺寸图。

结构依据：
[H3C 官方硬件描述 §2.8](https://www.h3c.com/cn/d_202602/2753207_30005_0.htm)
（图2-15 / 图2-16）。
品牌轮廓依据：[H3C 官方标识](https://resource.h3c.com/cn/tres/NewWebUI/2020/images/logo.png?v=2603)。
后续设备沿用色板、光照和端口部件规范，并依据各自型号调整端口、盘位和品牌标识。
