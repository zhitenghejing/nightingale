# 机柜设备素材库

本批包含前 10 个选定型号：9 款服务器及 H3C S5130S-28S-EI 交换机，
每型号一组正面、背面，共 20 个面板。不区分面罩、硬盘数量或盘位变体。

- `originals/`：网上收集的原始产品图片，保持下载字节，包含实拍及厂商产品渲染图。
- `vectors/`：用户确认后的 20 张纯矢量源文件。统一正交视角、绘制方式和光照，
  保留每款产品的颜色、品牌标识与面板特点，不含嵌入位图。
- `panels/`：项目实际加载的独立 SVG，与已批准的 vectors 源文件保持字节一致。
- `photo-panels/` / `photo-catalog.json`：切换前的照片版面板与目录，保留用于追溯。
- `vector-draft/`：制作和评审历史；以后修改草稿不会自动影响已发布素材。
- `catalog.json`：稳定素材 ID、标准型号/品牌、别名、标准 U 高度、正背面资源、原图链接、
  来源页面、显示窗口及原图/成品 SHA-256。
- `来源清单.csv`：20 条可追溯的素材来源。
- `index.html`：离线正背面对照总览。

来源页面未声明开放许可，来源和权属说明原样记录于目录；不将素材标记为自有摄影或开放授权。
素材仅代表该型号的一种配置，实际网卡、硬盘、电源配置以资产及设备本身为准。

## 项目集成

在 CMDB 资产弹窗选择「设备素材型号」可同时填写标准厂商、型号和设备类型。
已录入资产按品牌别名和完整型号自动匹配。匹配时只规范大小写、空格、标点及明确登记的
型号别名，不做子串匹配。例如 DL380 Gen10、Gen11、Gen10 Plus，以及 R750、R750xs
不会互相套用。R650 是 1U，R750 是 2U，位置高度不符时提示核实并禁止在弹窗提交。

`assetMaterialId` 保存到已有 `cmdb_device.payload` JSON，未新增数据库列或表。
服务端原有 JSON 读写会保留该 ID。CSV 包含素材编号；导入同样执行素材匹配与高度校验。
旧资产无需批量改写，在机柜图中按原字段即时匹配，后续编辑保存时写入稳定 ID。
未匹配、ID 与型号冲突或高度不一致时，机柜图显示明确的占位面板，不套用相似型号素材。

正视图和背视图使用同一资产、同一机柜及同一 U 位；切换不写数据库，也不镜像设备素材。
两种视图均支持弹窗编辑和拖动移动。

## 重新打包与归档

```bash
python3 scripts/build-cmdb-materials.py
# 仅在授权写入桌面时执行：
python3 scripts/build-cmdb-materials.py --desktop /home/zt/Desktop --replace-with-backup
```

桌面归档位于 `素材/机柜设备素材库/服务器或交换机/品牌/型号/`，包含独立正背面 SVG、
原始图片和来源 JSON，并提供根目录离线总览。默认拒绝覆盖不同文件；显式 --replace-with-backup 会先将旧桌面库完整备份到
`素材/历史备份/机柜设备素材库-时间戳/`，再更新副本。

## 已发布版本

当前为 `product-vector-v1`。每张面板使用 `1200 × (120 × U数)` viewBox。
R740 使用用户确认的蜂窝面罩参考，按照片修正中排 5 个完整孔、上下错位及边缘截断；
H3C 上排网口卡扣朝上、下排朝下。品牌 Logo 使用矢量轮廓。
素材采用参考配置的简化外观，不是精确 BOM，也不代表设备运行状态。

catalog.json 通过 renderKind/vectorSource/vectorSha256 区分已批准的矢量源与参考照片。
原图 SHA-256 与面板 SHA-256 分别记录；重新打包校验两者，不能悄悄回退为照片版。

机柜显示尺寸与素材原始比例可能不同。已发布 SVG 使用 `preserveAspectRatio="none"`
填满设备容器，避免默认等比缩放造成左右或上下黑边；打包时会校验此属性。
