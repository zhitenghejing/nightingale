# THROWAWAY：统一知识与资料协同静态原型

问题：客户文档和故障知识如何共用检索，并在同一会话中从资料问答自然进入现场排查？

仅用于看页面，未实现正式功能。所有数据和操作在内存中演示，不调用接口、模型，不读写浏览器存储，不修改原有页面。

直接打开 `knowledge-unified.html`，或运行：

```bash
python3 frontend/src/pages/opsKnowledge/prototype/serve.py
```

打开 http://127.0.0.1:30418/knowledge-unified.html 。

同一页面提供 `?variant=A|B|C&view=documents|knowledge|chat`：

- A 原有页面增强：保留夜莺主导航，文档、知识与会话分页面串联。
- B 知识与会话并排：收窄主导航，项目资料目录常驻，资料与会话相邻。
- C 任务步骤工作台：顶部主导航，按入库、检索、分析串联，侧边保留任务上下文。

底部左右箭头或键盘 ← → 切换布局；输入中不拦截箭头。页面标签切换三个业务画面。

可体验：上传示例文件、已有资料初始化入口、摘要失败重试、关键词结果及空结果、来源原文/Markdown/摘要、引用到会话、同一会话结合现场示例、查看证据、知识同步配置。刷新清空演示状态，查询参数保留布局与页面。

同一知识空间用于问答和排障；资料中的操作说明不等于已批准操作。未实现 OCR、语义检索、Embedding 或重排序。

此原型尚未选型或转正式实现，无生产路由及数据库变更。
