# 静态原型修订：沿用档案管理与现有 AI 会话

2026-11-16 根据用户截图收敛为一个布局，不再比较之前的三种全页布局。仅改独立 HTML，未修改正式菜单、页面、会话逻辑或数据库。

直接打开 knowledge-minimal.html；也可运行现有 serve.py 后访问 http://127.0.0.1:30418/knowledge-minimal.html 。

- 原有“档案管理”上传附件，自动整理到现有“运维知识”；不增加“文档管理”菜单。
- 保留 Nightingale AI 原有双侧栏、欢迎页、推荐卡片与输入框；仅在输入框底部增加“+”模式菜单，提供运维助手/资料问答。选择资料问答后显示小标签，不放顶部模式横条。
- 不展示资料范围、客户空间选择条；以登录账号真实权限在后端工具层过滤。Agent 依授权工具的结果答复，不由模型自判或授予权限。
- 对已指定资源读取返回 403，回复“没有权限查阅”；在授权集合内搜索为空则回复“未找到相关资料”。不能先搜索无权资料再泄露其标题、片段或存在性。
- 原型的问答、原文与权限结果均为示例；现有正式档案权限尚未改变，不能宣称本次已完成真实权限隔离。
- 原文与派生知识共用权限规则。普通文档仍可辅助排障，切换模式保留会话与资料引用。
- 没有 Embedding、语义检索、重排序或实际模型调用；模型、监控与鉴权尚未联调。

链接参数：

- ?page=chat：原有欢迎页与底部 +。
- ?page=chat&menu=1：直接展示模式菜单。
- ?page=chat&state=answer：资料回答与出处。
- ?page=chat&state=forbidden：无权限回复。
- ?page=chat&state=empty：没有找到资料回复。
- ?page=archives：既有档案详情，附件表增加知识整理状态。
- ?page=knowledge：沿用运维知识入口显示已整理资料。

可点击 +、模式、发送、原文/Markdown、档案菜单及演示上传。输入包含“指定档案/受限”时演示无权限，包含“2026年12月/不存在”时演示未找到；这些匹配只用于静态状态演示，正式功能必须依工具结果。所有状态只在内存中，刷新重置。

正式实现需持久化模式，后端限定工具/执行路径并在检索、原文读取和历史引用时校验权限。本轮没有执行这些功能开发。
