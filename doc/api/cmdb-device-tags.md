# deviceTags：CMDB型号与所属业务

本轮按用户确认，将配置草稿的deviceTags来源由规则附加标签改为同一CMDB资产的型号(model)和所属业务(business)，顺序固定。示例JSON字段：

```json
{"deviceTags":"['R650', 'HIS']"}
```

字段仍是字符串，不是JSON数组。单引号、反斜线及控制字符进行转义；任一值为空或空白时阻止发送。仍支持旧来源，不自动批量改写其他通知规则。新来源也可独立于设备名称来源使用，但必须显式配置CMDB匹配条件。

界面“查找CMDB的告警标签键”不是接口输出字段。例如CMDB匹配字段选hostname、标签键填ident，是用告警标签ident的值查找主机名相同的资产。找到后type→deviceType、hostname→deviceName、model/business→deviceTags；不自动推断ident存在，不自动选择资产。

CMDB适配查询只增加model和business两个必要字段；来源在首次任务登记时冻结。重复登记复用首次快照，恢复沿用已受理故障；源资产后续修改不改变原报文。没有schema或导出入口签名变更，edge仍通过原CenterApi提交、center完成读取。媒介和配置草稿保持关闭；不创建真实推送任务，不访问1.0接口。
