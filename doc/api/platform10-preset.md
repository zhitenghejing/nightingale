## 可靠性边界

CMDB没有已索引的主机名/IP列，当前只扫描活跃资产文档的必要存储字段，无全量机柜/磁盘读取；大规模资产性能未验证，不宣称已完成生产容量验证。此查询是center内部告警适配读取，不新增面向用户的CMDB API或修改资产/Target的绑定。

来源冻结时刻是首次任务登记，尚不是告警产生时的历史资产/规则版本；登记前规则或CMDB变化仍可能影响首次取值。读取失败会保留具体校验原因；修正关联配置后使用新派发验证，不把旧失败快照伪装为已发送。既有首次登记前崩溃窗口、快照大小上限、多center/edge部署未验证等边界仍存在。未新增下游人员匹配、短信电话或状态查询。
