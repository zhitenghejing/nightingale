已完成档案 `.xlsx` 上传、原件和历史版本保留、只读工作表阅读、后台知识整理及 Agent 表格查询。模拟报告在当前默认真实模型 MiniMax-M3 下完成两轮资料问答，求和、筛选计数和末行记录均与预期一致。此次未生产发布。

## 如何体验

1. 进入档案管理，新建或打开档案，在“文档资料”上传 `.xlsx`。旧 `.xls` 先另存为无宏、未加密的 `.xlsx`。
2. 点击“阅读”，切换工作表或输入单元格范围，查看隐藏标记、合并范围、保存的单元格值；点击“下载原件”取得未改写原件。替换仍使用原有编辑租约并保留历史正式版本。
3. 等待后台整理，在 Nightingale AI 输入框的“+”选择“资料问答”，询问文档内容或表格统计。工具自动核对账号、当前正式版本，回答带文件 Vn、工作表和范围链接。

## 实现与边界

`pkg/workbook` 统一负责上传校验、工作表只读、Markdown 转换及范围查询；知识工作器在同一租约事务中写入 Markdown 小节和 `knowledge_document_workbook` 快照，复用正式版本、摘要重试、关键词检索及环境候选机制。`query_knowledge_workbook` 不接受身份覆盖，不执行 SQL、脚本、宏、公式或外部链接。

工具执行时检查登录账号与当前源版本；资料问答模式还在最终回答、历史上下文复用前重新核对。档案权限沿用现有有效登录账号可读规则，本次未新增客户级文件 ACL。历史问答是留存记录，旧答案不会因换版被改写；再次问答不能把失效来源当当前证据。

Excel 是资料来源，未改作资产台账，不写设备列表/CMDB，不改独立根因分析工作流。无 Embedding 或重排序模型。仅普通 `.xlsx`，不支持在线 Excel 编辑、旧 `.xls` 解析、宏和加密工作簿；图表、图片和批注不提取文字，原件保留，未做 OCR 验收。合并格不复制填充，隐藏数据在明确范围内参与统计；表头、合计、单位和日期含义仍需依据原表确认。空目录或单元格缺值不能推出实际环境没有对象或已经正常。

预算：原件 50 MiB；解压总计 128 MiB、单项 32 MiB、ZIP 条目 3000；工作表 32、坐标范围 100000 行/256 列、单元格 XML 条目 100000、非空单元格 50000；展开文本 8 MiB、隐藏/合并元数据 1024 项、Markdown 2 MiB、结构化快照 16 MiB；解析并发 2。超限明确报错，不静默宣称完整覆盖。复杂损坏文件和不同厂商的所有格式变体尚未穷尽测试。
