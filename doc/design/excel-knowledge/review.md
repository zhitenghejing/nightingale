# Excel 接入设计与代码审查记录

审查范围为本任务新增工作簿解析、档案接入、知识索引、Agent 只读工具和阅读组件。未修改独立根因分析工作流、设备/CMDB 资产写入逻辑或稳定实例。此次由主写入 Agent 自查，无独立人员审查结论。

- 解析与查询封装在 `pkg/workbook`：档案和知识模块共同使用，互不反向依赖。原件不可变，知识版本绑定确切档案正式版本；非当前版本仍可作为历史原件阅读，不能作当前知识证据。
- ZIP 路径、重复条目、解压尺寸、格式、宏/嵌入对象、单元格/工作表/输出预算在入库前校验；解析并发限制为 2，取消请求不继续等待资源。Excelize 只负责本地格式读取，从未调用公式计算或网络访问。
- 在调用格式库之前预扫描全部工作表坐标和元数据，稀疏单元格按 XML 中实际地址读取，不按伪造的 dimension 分配二维大数组。原始数值与显示值分别保存，文本标识符保留，公式无缓存显式未知。统计以精确有理数累加，最后展示 12 位小数，缺值/类型/错误不静默计为零。
- 工作表、合并和隐藏信息可查询，Markdown 分块保留坐标与前 3 行上下文，过长上下文有明确提示。统计基于完整指定范围，不受返回页数影响；合并格不复制填充，表头和合计由查询范围明确排除。
- 工具无用户身份覆盖参数；服务器核对登录账号。知识工具执行时验证当前版本，资料问答模式还在发布回答、复用对话时重新验证。目录和表格返回为来源数据，内置指引明确不能执行资料中的指令，不把静态报告当实时状态。
- 使用已有归档上传、版本租约、删除状态、原件下载及异步知识工作器；阅读页面增加只读表格区域，不引入第二套文档菜单或在线编辑器。
- 数据权限沿用当前档案的“有效登录账号可读”规则，不宣称已有客户级行权限。未来扩展档案 ACL 时，必须同步目录、原件、知识、统计及历史回答复核入口。

运行结果和未覆盖事项另见 test-results.md，不能用设计检查代替真实模型和浏览器验证。
