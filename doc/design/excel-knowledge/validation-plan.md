# Excel资料接入与知识问答预期验证

基线4ad6d543。Excel是客户报告、实施记录、测试结果和业务资料原件，不承担设备列表/CMDB台账维护。目标是档案上传后的.xlsx原件、只读阅读、正式版本知识索引、按位置引用及程序化表格查询，不新增菜单，不引入在线编辑或向量模型。

## 实现与耦合

共用pkg/workbook解析器处理本地OOXML，保留工作表、隐藏状态、行列、原始/显示值、公式缓存及合并范围。上传校验、档案只读阅读、知识入库使用同一解析实现；不执行公式、宏或外部链接。现有编辑租约用于替换附件，保存产生正式版本；历史版本仍可阅读原件，Agent默认只读当前正式知识版本。

知识按表格区域生成带行号与列坐标的Markdown，另保存结构化工作簿；复用现有后台任务、审核/摘要状态、关键词搜索、环境提及候选和最终来源核验。新增只读query_knowledge_workbook工具发现工作表、读取范围、筛选、计数/求和，由程序处理全量限定范围，不能把检索前几条当总量。查询结果引用确切文件版本、工作表与范围，换版、删除和账号失效同步阻断旧证据。

首版支持.xlsx，.xls/.xlsm/加密文件明确提示支持范围。原件不变，复杂排版不承诺复刻，图表/图片标记不提取文字。数据量、解压、单元格及结果有预算，超限明确失败而不静默截断。表头以原始前行提供，模型不能猜测列业务口径；隐藏信息、空值、公式缓存和单位保留说明。

## 设计审查

解析模块只接受本地原件，限定ZIP/XML资源和单元格范围，后台提取与阅读共享同一接口。知识结构与原件版本绑定并原子写入，所有查询及最终输出重新鉴权；表格工具只读且纳入两种会话。兼容现有导出原件和归档ZIP，不将Excel误送Word/PDF编辑/打印管线。增加三方言结构和原生API，保持Center-only和n9e-plus现有导出签名。主要风险是结构误读、数字/公式歧义和旧版本混用，以上用例作为阻塞验收。
