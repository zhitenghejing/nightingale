# 环境关联实现审查

基线为存档提交5b14b433，单一作者实现并对照基线分开审查。

## 规范审查

新模块只在Center中读取原生模型；现有导出入口与edge/alert远程读契约未变。模型、gorm、三方言初始化和升级SQL配套。前端只在现有设备、CMDB、知识阅读入口增加共享Ant Design弹窗，不新增菜单、框架或依赖。内置知识Skill继续采用固定版本内容，不执行来源指令。源目录、凭据、实际会话和原文不进入交付报告。

## 需求审查及修正

- 不把同名/同IP对象合并；明确类型引用及已保存映射。
- 首轮权限审查发现采集设备投影可能暴露无权读取的资产引用，已移除原始asset_ref，只在两端授权后返回绑定；新增普通用户测试。
- 源身份指纹排除心跳，保留IP、归属、绑定、资料版本变化；过期/变化关系不参与遍历。
- 补齐图遍历的节点/边上限顺序，避免返回没有对应节点的边；循环终止。
- 工具结果的顶层截断标记与内部结果保持一致。
- 资料候选按保存人的权限重试，不提升到管理员；确认前只表示“资料提及对象”。
- 关联与业务对象修改使用乐观锁及审计。旧知识/查询证据在最终回答和后续会话中复核。
- CMDB台账变更与完整IT变更记录区分；当前未接入网络/部署变更平台，不据此宣称完整覆盖。

## 验证边界

行为测试及显式配置的三方言测试已通过。工程门禁、运行实例、浏览器与真实模型结果按最终测试报告记录；人工验收由用户完成。语义检索、自动网络发现和根因分析执行不在本期范围。

最终补查：采集端口/协议/启用状态纳入来源指纹；未解析资料返回处理状态；候选拒绝后不因后台重扫重新开启。环境和实时结论纳入无工具的独立核验，核验输入去除重复指纹并保留方向、有效状态、采样及截断限制。完整E2E已从修正后的脚本执行16项断言，真实模型分别验证模拟环境与真实shared-prometheus。最终完整门禁、重启数据摘要及人工验收边界见实际测试报告。
