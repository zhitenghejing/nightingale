# 环境关联首期和二期开发及预期验证

基线存档：`5b14b433`。目标是让现有资料问答和运维会话能识别实际对象、查询可靠关系并结合现场证据回答；不修改另一分支的根因分析，不引入向量模型或图数据库。

## 首期范围

新增 Center 环境上下文模块，复用 Target、模板采集设备、CMDB、已解析档案知识版本。业务/应用对象按业务组维护。关系包括所属业务、部署、依赖、监控映射和资料描述；原始记录按来源实时读取，人工关系保存对象指纹、有效期、来源和版本。读取时重新校验双方权限和有效性。现有设备详情、CMDB详情、知识资料阅读抽屉增加“环境关联”按钮和同一弹窗，不新增菜单和布局框架。新增只读 Agent 工具并纳入最终回答与历史重放的证据校验。

## 二期范围

从正式文档中精确匹配授权对象标识，生成“资料提及对象”候选；不自动推断部署和依赖。候选需人员确认，过期文档和变化对象不可确认。上下文按需汇总相关告警与 CMDB 审计变更，原生采集设备与资产绑定作为来源明确的现有关系返回。提供有限深度依赖查询、覆盖缺口及过期关系提示。源删除、撤权和身份改变即时阻断读取；不以模型猜测或全网自动扫描补关系。

## 测试资料及隔离

使用 Sim-ESB、Sim-VIP、Sim-F5-A/B、Sim-App-A/B、Sim-DB 构造与真实医院路径类似的隔离场景；标签明确 simulation，包含第二院区同名设备、相同IP冲突、过期报告、权限不同的业务组。实时指标复用只读 shared-prometheus 已采样对象；模拟设备不伪造真实采样，不向共享 Prometheus 写入。测试数据库/关系与用户资料区分命名，报告不包含凭据和客户原文。

## 开始开发前确定的预期结果

| 编号 | 阶段 | 输入/操作 | 预期可观察结果 | 验证方式 |
|---|---|---|---|---|
| E01 | 一 | 精确标识及同名对象查找 | 唯一标识可定位，同名/重复IP保留多候选 | 单测、接口 |
| E02 | 一 | Target、采集设备、CMDB、正式知识读取 | 只返回白名单字段，不返回凭据或原件私有字段 | 单测 |
| E03 | 一 | 维护业务对象及人工依赖链 | 保存来源、有效期、操作人和版本；双端均有权限 | 单测、UI |
| E04 | 一 | 普通只读用户、跨组或无CMDB权限 | 不能写；不能通过边或搜索泄露受限对象名称/数量 | 单测、接口 |
| E05 | 一 | 删除对象、修改IP/绑定、撤销权限后查询 | 对应关系失效或不可见；最终回答/历史证据校验失败 | 单测 |
| E06 | 一 | 心跳更新 | 不使对象身份关系无故失效 | 单测 |
| E07 | 一 | 重复提交、并发旧版本修改 | 不重复建边；旧版本拒绝；取消/撤回可追溯 | 单测 |
| E08 | 一 | Agent 查询环境及实时指标 | 实际调用环境工具，精确对象，依据来源可追溯 | 模型联调 |
| E09 | 一 | 无关联/未接入采样 | 明确未知，不能宣称正常或影响范围完整 | 单测、模型 |
| E10 | 二 | 文档包含精确设备标识 | 只生成候选，正式依赖图不自动改变；重复扫描不重复 | 单测、UI |
| E11 | 二 | 确认/拒绝候选、文档新版本发布 | 有权限人员确认；旧版候选不再可采用 | 单测、接口 |
| E12 | 二 | 三层关系及循环依赖 | 按方向、深度、数量上限返回；循环终止并说明截断 | 单测 |
| E13 | 二 | 对象相关告警与CMDB审计 | 限时、限条，保留事件时间；不将资产审计称为全部变更 | 单测、接口 |
| E14 | 二 | 部分端点受限、候选、过期边 | 从正式依赖遍历中排除，不泄露受限关系 | 单测 |
| E15 | 共用 | 现有设备/资产/知识抽屉打开关联弹窗 | 原框架保留；搜索、新增、查看、撤回、错误重试可用 | 浏览器 |
| E16 | 共用 | 三数据库初始化/重复迁移 | PostgreSQL/MySQL/SQLite均成功、唯一及乐观锁约束有效 | 外部数据库测试 |
| E17 | 共用 | 重启、现有告警/会话/资料流程回归 | 关系持久化；原功能回归通过 | E2E、工程门禁 |
| E18 | 共用 | 实际构建与交付 | 源码前端匹配、本地/LAN/公网核验、可下载报告实际校验 | 运行实例 |

阻塞项：越权泄露、把候选当正式关系、无依据确定对象、凭过期关系下结论、修改生产/共享数据。自动测试、真实模型、浏览器与人工验收分别记录。最终报告逐条列实际结果，不以未运行用例替代通过。

## 设计审查

采用原生来源引用和人工关系分离；每次查询动态授权，来源指纹排除心跳字段，资料版本按当前正式版检查。资料自动候选只用明确标识而非型号/相似名称。环境工具有服务端白名单、结果及遍历上限。关系状态不是告警状态，不触发执行。主要风险为身份复用、跨模块权限及错误方向；由 E01/E04/E05/E12/E14 验证。既有导出入口和 edge/alert 热路径保持兼容。
