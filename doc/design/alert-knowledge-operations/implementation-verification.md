# 首版实现与实际验证

## 交付范围

已实现“原生告警 → 持久处置 → 正式知识匹配 → Agent 取证与提案 → 人员确认 → 程序验证恢复 → 人员结束 → 知识反馈草稿”。源码位于 `brawny-skunk`，基线 `2ba46536d42203fadc7f124e72d900f467044059`。没有推送、合并或生产发布。

这是可供验收的首版功能。模型连接、生产 Ibex 执行默认关闭；演练使用独立数据源、固定测试动作和本地脚本化模型。真实模型、真实 Ibex、医院业务资料与现场人工验收仍需单独完成，不能由演练结果替代。

## 设计与代码审查

一个主要 Agent 实施并进行单独审查；没有代替人工验收。审查覆盖基线以来的完整工作区差异和新增文件，包括模型/三种 SQL、Center 生命周期、路由与权限、Agent 工具分发和预算、审批与恢复、前端入口及配套资源。

已处理的主要问题：

- 事务内知识读取复用同一 DB 事务，避免单连接测试死锁；统一 case/run 加锁次序。
- 受限工作流在内建工具分发前检查允许集合，并按真实工具调用数限制预算。
- 人工步骤只能由人员登记；指标步骤必须引用相同查询的成功证据；同 generation 人工步骤完成后可继续自动取证。
- 同版本重复采用保持幂等；背景、换版或合并使旧阶段证据失效；新一轮同对象同规则异常要求重新观察。
- 操作提案绑定现场证据基线，新证据到达后重新提案，旧提案失效；未知或未核实动作阻止后续执行与关闭。
- 验证使用底层采样时间，空值、旧值、截断及覆盖不足不能证明正常；业务未通过不结束。
- MySQL 单字段唯一索引重复迁移问题改为显式唯一约束，并在实际 MySQL/PostgreSQL/SQLite 复验。
- 隐藏只读人员不可见的草稿及草稿标题；附件下载重新鉴权并核对摘要。
- 手机窄屏控件与卡片换行、表格独立横向滚动；不以页面整体禁止滚动掩盖被裁切控件。

本次未发现尚未处置的阻塞工程问题。实际模型推理、院内适用性和生产执行不在该审查结论的证明范围。

## 运行实例与浏览器

完整业务 E2E 使用实际生产前端、真实登录、私有 PostgreSQL、独立 Prometheus、原生告警引擎、后台 scanner/worker 和固定 Demo 应用。Agent 经真实 HTTP 模型协议调用同一受限工具链，模型端点为明确标注的本地脚本夹具。

自动化入口：`scripts/ops_e2e.mjs`。必须显式设置开发预览 URL、build ID、私有凭据文件及私有输出目录；脚本拒绝非开发实例。登录请求不录制 trace/video，报告不含凭据。该脚本仅用于明确启用 Demo 的隔离预览，并通过人员通道清理前次同场景夹具，不能在生产运行。

已实跑通过：

1. 匿名接口/附件拒绝，错误密码拒绝，正确登录，正式知识版本阅读，私有来源下载字节一致。
2. 来源经 HTTP 生成草稿，验证日期为零且无可执行动作，直接发布被拒绝。
3. 测试目录水位变化产生真实采集指标和原生告警，scanner 自动创建处置，持久 Agent 工具循环保存证据并提出操作。
4. 未确认前没有执行，人员在实际 UI 确认后执行一次，重复确认返回 409。
5. 指标与原生告警恢复后，故意保持业务失败，验证项失败且关闭返回 409。
6. 解除业务/数据测试故障，全部必需检查通过后由实际 UI 结束；反馈保持未发布草稿。
7. 下一轮原生告警形成新处置；保留一个未批准操作供人工验收。
8. 页面直接刷新与手机布局无运行错误，工具栏控件没有被裁切。

完整闭环已验证构建为 `20261107T094846Z-be65587c`。之后的交付文档和证据资源更新不改变功能代码；最终运行构建由交付入口 `/__preview/info` 和交付时状态核验记录给出，不能只用 Git commit 代替脏工作区身份。完整闭环通过属于本机生产 UI 传输路径，公网浏览器检查与本地/公网探测分别记录。前端为本仓构建后附加验收资料的显式 file-assets 目录，前端源码摘要可与同仓 manifest 对照，未使用发布 UI 回退。

## 人工验收步骤

从准备入口进入并使用预览独立账号登录，打开“告警处置”：

1. 查看已结束的演练处置，核对来源、知识版本、证据和失败后再通过的验证记录。
2. 打开最新演练处置，查看尚未批准的操作及证据基线，按需先认领接管。
3. 确认固定测试清理操作，等待指标窗口及原生告警恢复，再运行恢复检查。
4. 核对业务和数据两项全部通过，填写结论结束；提交反馈后到“运维知识”确认其仍为草稿。
5. 需要重复演练时，在列表使用“演练故障”；若提案过期或证据改变，重新准备提案。

验收使用 Demo 自身 8 MiB 逻辑配额与测试账本，不填满宿主磁盘、不含医院数据、不执行生产作业。真实模型、医院资料梳理和院内只读取证试点由后续现场环境验收推进；人工确认与生产发布均未由 Agent 代填。
